# Demo guide

The step-by-step walkthrough is in [DEMO_SCRIPT.md](DEMO_SCRIPT.md). Before presenting:

* Plug the laptop in (latency on battery can be several times higher — KNOWN_ISSUES K14).
* `.\run.ps1`, open http://127.0.0.1:8000 once so the service worker caches everything, then disable Wi-Fi.
* Keep Settings → Motion on "Follow system" and choose the theme you will present in.
* Example messages in the app are written for the demo and use reserved `.example` domains.
